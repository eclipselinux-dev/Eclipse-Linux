The vision

Не очередная сборка.
Отдельная система.

Eclipse Linux задумывается как независимая Linux-операционная система. Проект будет развивать собственную архитектуру пользовательского пространства, инструменты и экосистему программного обеспечения.

◈

Собственная основа

Разработка собственной системы без Debian, Arch или другой дистрибутивной базы.

⌘

Свои инструменты

Системные компоненты и инструменты проектируются в рамках экосистемы Eclipse Linux.

✧

Единый характер

Лаконичная визуальная идентичность и последовательный подход к устройству системы.

System philosophy

Свой фундамент.
Свои правила.

Eclipse Linux не привязан к готовой базе дистрибутива. Это означает отдельную работу над системной инфраструктурой, пакетами, обновлениями и совместимостью. Детали реализации будут публиковаться по мере развития проекта.

Package ecosystem

Epkg — пакетный менеджер Eclipse.

Epkg станет центральным инструментом управления программным обеспечением Eclipse Linux. Для пакетов проекта предусмотрен собственный формат файлов — .ecx.

⬡

Epkg

Единая точка управления установкой, удалением и обновлением программ. Команды и возможности будут описаны в документации.

▧

.ecx packages

Собственный формат пакетов Eclipse Linux. Структура, метаданные и правила сборки будут определены спецификацией.

⇄

Package ecosystem

В перспективе — репозитории, инструменты сборки и процесс публикации пакетов.
